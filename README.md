# Minimal Academic Homepage

A responsive academic homepage template that keeps the complete site in one HTML file. It has no framework, package manager, runtime, or build step: edit `index.html`, replace the neutral SVG placeholders, and publish with GitHub Pages.

## Use

1. Fork the repository or download it.
2. Replace the placeholder identity, links, publications, projects, experience, awards, and notes in `index.html`.
3. Replace the three self-authored neutral SVG placeholders in `assets/` or update their paths.
4. Enable GitHub Pages from the repository root.

The template includes responsive layouts, semantic sections, keyboard-visible links, reduced-motion support, SEO/Open Graph metadata, safe external-link attributes, and a dependency-free validation check. Its narrow goal is a clear academic page that can be understood and deployed in minutes.

## Files

```text
index.html
assets/
  profile-placeholder.svg
  publication-placeholder.svg
  institution-placeholder.svg
tests/validate_template.py
```

The old personal profile, publication, and university images are not part of the neutral template and should be removed from the public release branch.
